# dev_setup

Linux install script for new machines and commands I can't remember.

## Quick Start

```bash
git clone https://github.com/AndrewBorst/dev_setup.git
cd dev_setup
chmod +x install.sh
./install.sh
```

## What's Included

- **Neovim** (latest stable via AppImage)
- **Python dev tooling**: pyenv, python3, pip, venv, black, ruff, mypy
- **Neovim Python support**: pynvim, kickstart.nvim config
- **Essentials**: git, curl, wget, build-essential, ripgrep, fd-find, tmux
